First packaged release of Filet, an experimental local file automation CLI.

- YAML and ESM JavaScript rules with inspectable `plan` / `apply` execution.
- A foreground daemon for file watching, reconciliation and rule reloads.
- SQLite operation history, conservative crash recovery and concurrent startup handling.
- A bundled agent skill, configuration examples, schemas and a macOS launchd helper.

## Downloads

| `filet-windows-x64.zip` | Windows x64 |

Download your package and `SHA256SUMS`. Intel Mac builds are no longer provided.
These Release attachments do not expire with the 30-day Actions artifact retention period.

No Rust or Node.js installation is needed. Each package includes the agent skill and
examples; ask your agent to read the extracted `skills/filet/SKILL.md`.
See the [installation guide](https://github.com/zxdvd/filet/blob/v0.1.0/docs/artifacts.md).

## Status

This is experimental 0.1 software: validate rules on disposable files before enabling
the daemon. macOS binaries are not Developer ID signed or notarized. The launchd
helper requires Python 3. Older OS compatibility and power-loss recovery are not
guaranteed; see the bundled operations documentation for the current boundaries.
